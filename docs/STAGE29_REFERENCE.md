# 阶段 29 原引擎参考

## 证据身份

Terry 原包为 `local-mugen/terry.zip`，SHA-256 `299203338248952735fd33b4951aba84b39580123290abd8ac70387580ff4698`。IKEMEN GO 源提交为 `5dac5caf9a02a9b81bf2264e88a1bbf68e21bba0`，标准探针复用阶段 27 可执行文件 `d319e3ab97c9f05c680c31268064bd8786b8dc72f625c97f6d1e23b45a3b98cd`。实际定义在 `Terry.cns`，其 SHA-256 为 `d1c25e17949ce0322742dd41cc4aa5a5490bf123a85803dfb5c2576460eb7fc1`。其余脚本、AIR、配置和每场轨迹哈希由 `run-metadata.json` 和每场元数据记录。

标准探针 75/75 通过，F100 的 `hit` 由同输入 F145 长记录补齐到受击方恢复。另有 23/23 个只读命令探针，可执行文件为 `e95a394e16b153b795b2a15fa1486e9f7458395943ace1f3ac48eef091855867`。两组重叠帧全部核对，比较仅略去只读探针新增字段和 F0 首次种子推进前残留的入场 `var(21)`。执行日志为 `local-mugen/stage29-native-check.log`。运行批次和核对命令见 [Stage 29 原版复现](../tools/Stage29Reference/README.md)。

所有场景用种子 1337。同一初始间距下，默认 P1 色板 1，模式 2 由色板 7 的实际选模式流程进入，P2 色板 2。输入和距离见 [原版场景](../tools/Stage29Reference/Cases.json)。`F` 是相对于该场记录起点的原版全局帧，旧 tick 是 State −1 求值时被退出状态的 `stateTime`。动作与碰撞框按 `after-collision` 核对。目标被击中的状态切换及本帧 HitPause 声明使用同帧 `end`，仍保留原版下一反应 tick 扣血与 NewKOF 接触 tick 提交的既有差异。

## 输入、优先级与自然入口

- `Helper.cns:2247–2256` 中 99999 收到同名物理命令写入 `var(7)=3`，同轮递减为 2。读根命令与 Helper 的独立取证使用同一 IKEMEN 提交下的只读探针扩展。在通常 F5 双键，F5 `after-command` 根为真／Helper 为 0，F5 `end` Helper 为 2。F6／F7 的 State −1 可读取旧 Helper 2／1，根已变为假，F8 已耗尽。
- 站姿中立、前和后均可发 250。初始距离 36（可投距离）前／后 y+b 均先进入 250，800 或 805 不抢占它。前＋x+y+b 也进 250，已完成 236 的 x+y+b 先走默认 1000。下＋y+b 回落 410，前下＋y+b 由合法 310 优先。优先级按 `Terry.cmd` 的具体资格求值。720 在 250 前，额外的 700／255 保护分支、空中 650 不作为本体入边。
- 原版根 `time=1` 的按键组合以 [附加命令记录](../tools/Stage29Reference/Install-TraceHooks.ps1) 直接观察。两键错开一帧，即使第一键仍按住，也不触发。先到的单键分别发 210 或 240。两键持续按住仅提交一次，释放再在 F54 新按双键可由 old 49 的自然许可重开。State 200 F5 空挥，F14 双键到 F17 已过期，F15 和 F16 双键分别利用尚活的 Helper 在 F17 正常进入。F16 持下双键、F17 松下也进入 250；F16 中立双键、F17 补下则走 410，方向在消费期重新判定。旧双键胜过同帧新 x，而同帧已经完成 236 的新 x 优先发 1000。旧 y 不抢同帧新双键。四键全按取证触发原版 760，该原版分支不在本阶段实现范围。
- 全局暂停边界沿用阶段 27 的 240→1000 样本，F102 正常自然恢复可进 250，F103 暂停 tick 的双键在 F104 以 Helper 值 2 进 250，F104 当帧双键由根命令提交。250 的角色 HitPause 中 F38 双键可使根命令保持到 F40，Helper 在 F38／39 分别为 2／1 并在 F40 变 0。此例仍在旧 250 窗口且不能自连，冻结中的采样不会创造额外 State 250。

## 取消、自然路径与模式

`Terry-2-3.cns:58–70` 使用 `AnimElemTime(11)>0 && AnimElemTime(12)<0`。11／12 是 **AIR 元素编号**，原始元素起点是 23／26。实际许可是 **旧 stateTime 24–25**，修正阶段 28 文档中的静态简称。

- `250→300` 按 `Terry.cmd:1538–1547` 使用 `var(1)=1`。空挥 F29/F30 分别对应 old 24/25。old 26 拒绝。当帧 F+x 根边沿有效，old 21/22/23 的有效 F+x 可在 old 24 由独立 Helper 路径进入，分别以可见 `helperForwardX=1/2/3` 为证。old 20 的按键已过期，前下＋x 不创建这条命令。站防与命中 F40 同样 old 24 可进。命中冻结中 F38 按键于 F40 解冻提交。
- 默认 250 **可以直接 236+x→1000**，`Terry.cmd:1141–1152` 的旧 24/25 接受 `var(1)=1`，原版空挥 old 24 与 old 25 实证，old 26 拒绝。模式 2 的对应路径进入 State 1050（1170–1182 行，实测 F29），与本体和 300 入边独立。阶段范围仅允许保留未接入的模式 2 1050。默认自然 F54 old 49 的 1000 是 `var(2)=1` 自然许可，不是直接取消。
- `250→310` 按 `Terry.cmd:1550–1560` 使用同一 `var(1)=1` 和独立 DF+y／Helper 入口。原版空挥 F29 old 24 进入；NewKOF 只保留 310 指令与独立范围。
- 250 old 24 单 x、重按 y+b 均无提前链。200 与 300 在未恢复时输入双键不能提前进入 250。原版 300 至弱 Wave 仍要求自身 old 18–19 且第二段接触。原版防御后 F40 转 300，F51/F68 两次防御接触，第二次接触冻结时完成手势，于 F80 旧 tick 18 进 1000，Helper F105 防御接触削血 9。
- 普通 250 命中 F28，F40 直取消 Wave，1020 在 F55 正常生成。距离 36 和 100 均在 F64 观察到活跃动画框与空中目标重合、但 Helper HitDef 属性仍为 0，到目标落地也无补发。若 F40 改为 300，其两段活动框 F51–53、F57–59 仍然绘制，根 `var(12)=1` 时两个 HitDef 属性均为 0。原版 `Terry-2-3.cns:498–538` 把未反击的 ID 30 击飞作为禁追分支。距离 100 且 P2 F27 新开 215 的反击对照，F28 实扣 130，F40 同样进 1000，Helper 于 F60 追加 89 并让空中 5050 转 5020。反击使用原版独立宽限分支，不能给所有 250 接触套相同禁追锁存。
