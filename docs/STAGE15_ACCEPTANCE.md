## 规则和运行对照

- 原版 `y` 进入 State 210，实验输入为 `5B`。原版调色板 7 开场输入 `Grant`（上、上、下、下、上、下）进入 `var(10)=2`。NewKOF 在开赛前选定预设，复用同一个 State 210 的战斗身份。Action 210 为 5/8/17，Action 211 为 5/7/18，均在动作 tick 30 结束。共存的轻拳 `5A` 仍为 3/4/5。
- 两个重拳的 Clsn1 为 X `[12,67]`、Y `[61,84]`。Action 210 的 AIR 上下端点倒置，导入器按实测规范化，原素材不变。两条重拳与轻拳各使用自己的动作 Clsn2，随 `MoveElapsedFrames` 推进及停顿，朝向使用权威镜像。
- 站立目标中心距 86 时边缘命中，87 时空挥。原版中心距 64 仍优先 State 215，64.5 和 65 进入 State 210。实验配置在距离严格大于 64 时允许远身重拳。近身条件成立时拒绝远身分支，State 215 的两段攻击仅有原引擎证据。
- 普通重拳 tick 5 接触，实扣 115，攻守停顿 11/13。站防与提前或接触 tick 蹲防均零削血、停顿 11/11。相对入招零点，命中目标 tick 37 可控，格挡目标 tick 34 可控，攻击方接触后 tick 41 回待机。首步击退 10.5，站姿摩擦 .85、蹲防 .82。受击画面从 5002 到 5007，站防和蹲防使用 150/151。
- 同 tick 对攻样本中，轻拳与重拳分别扣 54 和 154，双方独立停顿 13 tick。轻拳提前生效时以 54 点打断重拳，重拳无 HitDef。此处使用实测反击参数。原脚本 `var(21)` 由随机控制器逐 tick 更新，`var(6)` 在目标退离攻击状态后仍短暂保留。NewKOF 固定预设覆盖本次样本的起手与生效反击分支，随机伤害、反击延续时间、其他模式与取消保留为后续规则。
- IKEMEN 在接触后的目标反应 tick 扣血。NewKOF 保持接触 tick 提交，比较器分别检查两者。站防接触前及恢复控制后的移动仍遵循各自规则，硬直期间位移以各自接触位置归零，容差 0.004 世界单位。帧号只按各自首次入招固定归零。

## 本地证据

- `local-mugen/stage15-validation/fixed-v3/` 有 52 次固定 Vulkan 运行。覆盖开关的 2520 个逻辑帧与 10080 条权威日志一致。24 项有逐 tick 原引擎对照或近身拒绝检查，共 772 个采样状态，零差异。另两项验证双席多招顺序。保存 1636 张 FramePostDraw 图像及 `reference-diff.json`。最终构建另跑 `fractional/`，两种模式、覆盖开关共四次运行，760 条权威日志一致，84 个 64.5 距离状态通过原引擎对照。
- `default-overview.png` 与 `mode2-overview.png` 来自固定帧采集，可见命中闪白、站防、蹲防、两席镜像、打断和同时命中。入招状态为 20，普通接触状态为 25，重拳受击在状态 39、40、42 分别显示 5002 首帧、5002 后续帧和 5007。权威时钟与实际 SpriteRenderAudit、FramePostDraw 文件版本相互对应。
- 站防初验曾误用通用受击贴图，已用独立状态绑定修复。录制窗口失焦曾清掉按住的防御方向，验收用 `--capture-input-only` 重跑。同一输入处理器消费计划按键，正常交互的失焦规则保持。
- 实时 `real30-warm/default-hit/` 与 `real60-warm/mode2-mirror/` 为最终构建在 30/60 FPS 上限下的 Vulkan 图像证据。低分辨率、入场暂停预热后各采三张，均无积压告警。前者记录状态 17→19→23 的 Action 210 起手、命中、停顿，后者记录状态 21→24→26 的左向 Action 211 命中和停顿。帧率上限与实际绘制间隔分别记载。早期实时站防尝试因渲染计数注入时点与逻辑状态错位未格挡，站防由固定帧精确输入验收。
- 最终构建复跑阶段 14 的 State 200 门禁，640 个逻辑帧、2560 条权威日志与封版逐条一致。阶段 13C 的投技、道具、3v3 和取消门禁也通过，323 帧角色与实体记录及 69 条取消记录逐条一致。另有 `gpu-pixels-final.log` 中的 `MUGEN_GPU_PIXELS_PASS`。
