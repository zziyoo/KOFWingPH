# 阶段 18 候选范围

本记录仅审查阶段 17 所用原始 Terry 包中的 CMD、CNS、AIR 与当前 NewKOF 取消路径。此处的原版逻辑帧预测待 IKEMEN GO 实测，阶段 18 尚未实施或验收。

## 人类玩家站轻拳重进

- `Terry.cmd:311–314` 定义物理 `x`，命令 `time=1`。近身 State 205 控制器在 `1566–1581`，远身 State 200 控制器在 `1584–1598`。两者都要求对局进行中、非 AI、非 Helper、非空中且未按下方向。可走物理 `x` 或原角色 Helper 99999 的 `var(0)>0` 命令路径。Helper 与停顿期间的实际保持时间需逐帧采集，单靠 `time=1` 无法确定。
- 两个控制器都显式允许从 200 或 205 的 `AnimElem = 3,>=0` 进入。近身分支在 `p2bodydist X <= 16` 时优先，之后才是无近身阈值的远身分支。距离条件针对新进入的状态，所以脚本允许 200→200、200→205、205→205、205→200。以 Terry 双方站立前宽各 15 的既有配置，近身边界对应中心距 46，选招时使用当刻身体距离。相应触发组无 `MoveHit`、`MoveGuarded` 或 `MoveContact` 条件，空挥后也满足该组的静态要求。
- `Terry.air:558–588` 的 Action 200 与 205 均为 3／4／5 tick，第二元素有攻击框，第三元素是收招，按零基动作时钟由 tick 7 开始。`Terry-N.cns:15–111,117–211` 进入时设 `ctrl=0`、`MoveType=A`，元素 3 切 `MoveType=I`，动画结束返回 State 0 并恢复控制。真实 State −1 命令求值与 AIR 切元素的同一 tick 顺序须取证，避免把纸面 tick 7 直接写成最终取消窗口。

## 其他规则的边界

- 人类站重拳 215／210 位于轻拳之后（`Terry.cmd:1601–1623`），只列 `ctrl`、冲刺状态或 `var(2)>=1` 入口。200/205 的第三元素并未单独放行重拳。`Terry-2-3.cns:83–98` 对这些普通招式在 `AnimTime=0` 时设置 `var(2)=1`，因此同一招式末端的正常再起手需要与提前取消分开取证。现有阶段 16 已证明待机时 `x+y` 同帧优先轻拳。候选阶段应补测恢复中同帧输入。
- 人类同一收招条件还可进入站轻踢 235／230（近身 `p2bodydist X <= 28`）、蹲轻拳 400、蹲轻踢 430。反向进入站轻拳的其他来源为 235 元素 4、400 元素 3 开始后至少一 tick、430 元素 4。对应命令见 `Terry.cmd:1566–1598,1627–1659,1688–1732`。
- `Terry-2-3.cns:52–78` 的 `var(1)` 是另一组入口。State 200/205 处于第二元素内部时，即 `AnimElemTime(2)>0` 且 `AnimElemTime(3)<0`，设置 1，无接触确认条件。前加 `x` 的 300（`Terry.cmd:1538–1547`）先于站轻拳，斜下前加 `y` 的 310 同样可读取 `var(1)=1`。两个状态的后续接触触发可以设置 `var(1)=2`。独立的特殊技控制器也读取该值，例如 1000／1010、1050／1060、1100／1110、1200／1210、1300／1310、1400／1410、1450／1460、1500／1510、1550／1560、1600／1610、1700（`Terry.cmd:961–1288`）。超必杀入口在 `609–956`，还受模式、气量、生命或 Helper 等独立条件影响。若后续接入，应逐项复核，尤其原版 Terry 的 1200／1210 与 Kai 原型升龙属于不同状态实现。
- 上述入口属于人类玩家。AI 在同一 CMD 后段走独立控制器，部分路径另有 `MoveHit`、`MoveContact`、随机和距离限制。人类 `x` 重进不继承 AI 的命中确认要求。

## 首个独立验收单元建议

只接入阶段 17 预设中已有的 State 200/205 站轻拳及其四种重新进入路径。复用现有命令、近远距离条件、动作编号、HitDef、伤害脚本和表现层。先在真实 IKEMEN 对局用两次物理 `x` 捕获最早合法 tick、过早输入、最晚恢复 tick、HitStop 后窗口、命中／格挡／落空、阈值 46 两侧、同帧 `x+y` 和单次按键／长按。双向跨分支可用既有受击推移或合法步行建立距离变化，在记录中核对取消求值时的身体距离。对原版无法复现的组合保存触发条件与差异。

NewKOF 的 `TryCancel` 已支持按目标距离选招、消费一个识别结果、创建新的 `MoveStartedFrame` 并从动作 tick 0 开始。`FighterDefinition` 目前显式拒绝自身目标，见架构 D91。若原版实测确认同招重进，候选实现应给该规则显式可选配置，旧定义默认继续拒绝自身目标。验证旧实例的接触组、确认帧、受击去重和动作时钟正确清理，下一实例在合法帧可再次命中。用专项确定性测试与真实 Godot 固定帧、实时取证核对状态与画面，并通过相同输入下视觉覆盖开关的权威日志一致性。站重拳取消、其他普通技、特殊技、超必杀及 Helper 脚本解释留在该单元之外。
