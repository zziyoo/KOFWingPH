# 阶段 19 Terry 弱 Power Wave 取消源码审查

以下结论来自阶段 18 使用的 Terry 原始归档、固定版本 IKEMEN GO 的源码、阶段 19 首批原版轨迹和当前 NewKOF 内核。未覆盖的输入及实体边界仍待取证。

## 候选入口

- 默认模式 `var(10)=0` 的弱 Power Wave 使用物理 `~D, DF, F, x`，输入窗 16，默认命令缓冲 1。`Terry.cmd:166–169,1141–1152` 在人类、非 Helper、进行中的地面对局允许进入 State 1000。普通可控入口之外，`var(1)=1` 或 2 可直接进入。State 1000 的控制器先于 200／205 的站轻拳规则。相同输入在模式 2 走 State 1050，另有 `!NumProj` 条件和不同的实体脚本，见 `Terry.cmd:1170–1183`。
- `Terry-2-3.cns:52–70` 每次执行先清 `var(1)`，再对 200／205 的第二动画元素内部设置 1。条件是 `AnimElemTime(2)>0` 且 `AnimElemTime(3)<0`。AIR 时长与原版运行均指向旧动作有效 tick 4–6。该人类分支没有命中或格挡确认条件，合法空挥取消也属于同一规则。AI 后段另有带 `MoveHit` 的入口。
- 原版 Helper 99999 根据同一弱 Power Wave 命令将自身 `var(10)` 设为 12，随后按 `holdx` 每次减 1 或减 4。根角色 State −1 接受当前命令或 Helper 正值。固定 IKEMEN GO 的 `char.go:13919–13949` 在根角色 HitPause 内启用命令保持，并给该 MUGEN 1.0 角色在停顿中识别的命令额外一格缓冲。`input.go:2557,2707` 在停顿时停止衰减，解冻后再递减。该机制与阶段 18 站轻拳的固定年龄 2 有独立的时钟。
- 阶段 18 已知 tick 12 普通启动的混合缓冲优先级差异独立于此处的显式生效段窗口。新规则可只在源招式的生效段按配置优先消费完整 236A，站轻拳重进继续在 tick 7–11。无需为验证这一入口改写既有普通启动的全局 FIFO 规则。普通可控启动仅作为区分取消和终点恢复的对照。
- `local-mugen/stage19-reference/results` 的 `default-special-whiff-8` 至 `default-special-whiff-12` 已确认两个指令同时有效时的路由。最终 `x` 在 F9／10／11 分别以旧动作 tick 4／5／6 进入 1000，旧招未接触。F8 完成手势则由 Helper 值 11 在 F9 衔接，根命令此时已经失效。F12 完成手势时根 236+x 命令有效，但旧动作已到 tick 7，`var(1)=0`，原版改走同一按键的站轻拳重进。NewKOF 当前识别器会消耗同一按键的所有候选并仅保留优先级最高的结果。若直接添加高优先级 236A，后一个场景会丢失 `5A`，需要阶段 19 的显式候选保留和消费契约，旧角色继续使用已有裁决。
- `default-special-whiff-17` 的 F17 在旧动作 tick 12、`var(1)=0`、`var(2)=1` 进入 1000，是普通启动。补测 `default-special-terminal-heavy16-17` 中 F16 有重拳边沿，F17 的 Helper 重拳值仍为 2，CMD 仍优先进入 1000。要保留这个普通入口，需先在阶段 19 独立预设验证跨年龄的候选优先级。首批命中与站防对照在 F8 接触，F9–19 冻结。最终 `x` 在 F11、F17、F18、F19 的命中案例都于 F20、旧动作 tick 4 进入 1000，根动作指令仍有效，Helper 值分别为 −1、3、7、11。直接在 F20 完成手势也可取消。F11 松开后的物理输入已过 9 个全局 tick，仍能通过根命令保持启动。应分别表达停顿中的根命令保持与 Helper 衰减。

## 角色动作与实体

- `Terry-S.cns:6–57` 的 State 1000 站立、无位移、控制关闭，播放 Action 1000。真实 Manifest 的 10 帧持续时间为 `2,2,4,2,2,2,3,22,6,7`，共 52 tick，全部精灵通过资源审查。角色 AIR 没有攻击框。脚本在元素 7 时间 1 生成 Helper State 1020，原点相对角色 `(0,0)`，按素材时长为动作 tick 15。元素 8 切换 `MoveType=I`，预计 tick 17，`AnimTime=0` 返回 State 0。精确提交时刻以原版运行记录为准。
- `Terry-S.cns:132–462` 的弱分支使用 Helper ID 1000 和 Action 1020。Action 1020 有 11 帧 `1,2,2,2,2,2,2,2,3,3,4`，共 25 tick，精灵索引 `342,344–353` 均有效。AIR 的首元素无碰撞框，元素 2–7 有变化的 Clsn1 和 Clsn2。弱分支本地水平初速 2.5，在元素 7 置零。Helper 只在 `AnimTime=0` 销毁，接触后 `MoveContact` 关闭该实体后续 HitDef 资格，动画仍受实体时钟支配。State 1020 配置 `NotHitBy SCA`，与既有通用飞行道具互撞规则应单独实测。
- 弱 Helper 的两个 HitDef 分支都要求没有既有接触和反转。元素 2–5 首次接触可击飞地面目标，元素 6–7 的首次地面接触使用水平击退。两者都有 `MA` 防御及削血，原脚本停顿为发射侧 0、目标命中 13／格挡 11。伤害表达式从根角色读取 `var(6)`、`var(21)`、`fvar(7)` 和 `fvar(0)`，对完整乘积向下取整，和阶段 17 普通技先取整再乘攻击倍率的运算位置不同。两段共享一次接触资格。需验证第二段只在第一段未接触时结算、命中后的尾段画面、发射者被打断前后和左右镜像。
- `default-special-whiff-9` 中 200 空挥后 F9 取消，F24 出生的 Helper 已按 +2.5 移动，F25 早段命中造成 76，F26 目标生命为 924。目标震停 13，角色 1000 未冻结。F35 Helper 速度归零并继续显示尾段。中心距 180 的全空挥对照在 F49 标记 Helper 销毁，根角色 F61 恢复。受击触发后的 IKEMEN 运行步间距存在变化，使用源动作时间和动画元素核对 Action 1000 总长。其余运行对照见[阶段 19 原引擎取证](STAGE19_REFERENCE.md)。
- 原脚本的 `ParentVarSet`／`ParentVarAdd`、量表、特殊受击状态和模式 2 的 1050→1070/1071 路径有独立条件。模式 2 的 Action 1071 是有意空白，Action 1070 承担可见画面。弱 Power Wave 的命中和防御参考特效 Action 6002、6012 的精灵均通过资源审查。
- `Terry-S.cns:374–377` 在 Helper 命中后设置根角色 `var(31)=1`。`Terry-2-3.cns:624–640` 等待目标震停结束后递增该值，再按状态时间偶数 tick 触发 `Pause time=1`，至计数 25 复位。晚段命中运行中，原版世界 F48／54／60 的 `globalPause=1`，角色的 `HitPause` 为 0。无接触样本的角色退出与 52 个世界 tick 一致，命中样本需同时核对局部时钟和全局 Pause。

## 最小验收边界

- 人类 State 200→1000 的源入口证据涵盖命中、格挡、合法空挥、动作窗口边界、实际停顿、普通启动及镜像。State 205 共用源码谓词，近身空挥样本 F13 发动 205、F17 进入 1000。模式 2 作为分支隔离证据。下一步用独立预设和既有 `CancelDefinition`／实例状态验证新招从 tick 0 开始，旧命中确认和去重不会继承。阶段 17 的每席 RNG 延续按既有范围处理，取消不能重新播种。
- 完整 Power Wave 结算还需源实体时钟、分段攻击框、保留初始朝向的停速、接触后尾段、削血、命中／格挡分别配置的目标停顿以及源伤害运算。现有实体 ID、快照、固定帧、视觉开关权威门禁和每实体图形节点可以复用。现有默认投掷物在寿命内使用固定碰撞框，恒速移动、接触立即消失、固定伤害及零削血。若首单元只完成入招和原始角色画面，应把实体结算与受击列为未验收，禁止以 Kai 原型飞行道具替代原版结论。
