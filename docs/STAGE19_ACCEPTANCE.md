# 阶段 19 Terry 弱 Power Wave 验收

范围为默认模式 State 200 的显式取消、普通启动、State 1000 和 Helper 1020。预设只通过 1v1 实验参数加载。原版规则、模式差异和已保存的输入见[原引擎取证](STAGE19_REFERENCE.md)。

**阶段 19 PASS**。固定帧对照、实时 Vulkan 采样、确定性重放及阶段 13C–18 历史回归通过。兼容边界见下文。

## 矩阵

- 输入候选与取消。对照同一轻拳边沿、按键年龄和合法窗口。tick 4–6 启动 1000，tick 7 回落到 200，tick 12 按原版 CMD 选择当前轻拳或弱 Power Wave。原版 F8 早输入由 Helper 保留，F11 冻结期间输入由根命令保留至 F20。验证长按下、松键、过期、非法无手势、双席、重复按键及旧配置 FIFO。
- 角色与实体。Action 1000 从新实例 tick 0 开始，15 tick 后创建 Helper，启动当帧移动 2.5。Action 1020 的年龄决定分段矩形和位移，age 11 停止，age 25 移除。接触后保留演出但停止该实体的结算。双方实例分别使用权威 ID、冻结时钟、朝向和伤害状态。原版确定的早段击飞、晚段击退、削血、目标停顿、生命周期和原版禁止普通相杀的场景分别核对。
- 打断与回合清理。双发对局双方均被打断，已出生的实体继续到自然销毁。专项另覆盖发射前打断不生成实体、早段触地同 tick 再受击、起身保护、命中与削血 KO 清理。实验配置只用于 1v1，多人换人流程沿用阶段 13C 的实体交锋门禁。
- 周期性全局 Pause。Helper 实际命中后启用独立计数。按目标震停和发动者的本地状态时间排程，双发中后执行的源角色可观察前一角色同 tick 结束震停。Pause 保持角色、碰撞、实体和 RNG，同步提交输入与状态帧，角色 HitPause 计数保持。普通格挡没有脚本 Pause。
- 预防御。原版 `Constants.cns` 的前方距离为 230，两端采用严格比较。招式和 Helper 各自的 `MoveType` 决定威胁结束时间。沿用原版持续按后，轻拳在 L22（F8）以 X30 格挡，Helper 在 L50（F36）格挡、削血 9、目标震停 11。接触 X60.734207 与原版 X60.73532 相差 0.001113，固定点容差为 0.002。此处按后停步与格挡命中画面已核对，预防御入姿／退出动作仍用原有站姿投影。

- **19A/B 输入与取消 PASS**。同边沿回落、命中／格挡／空挥、旧招合法窗口、根命令与 Helper 的不同保留时间及旧 FIFO 均有专项和对局对照。
- **19C/D 角色、实体与结算 PASS**。State 1000 与 Helper 1020 的身份、位置、生命周期、早晚段命中、格挡、镜像、双发和恢复均有固定帧证据。
- **19E 全局 Pause PASS**。原版带全局 Pause 标记的样本与已提交世界 tick 一致。快照回放与可见实体连续性专项通过。
- **19F 历史差异核对 PASS**。在阶段 19 预设修正 CMD 优先级及预防御停步。两条已知独立轻拳接触差异显式进入对照报告。
- **19G/H 图形与回归 PASS**。固定 60 FPS、实时上限 30／60 FPS、覆盖开关、原版轨迹及历史门禁均有实际运行记录。

## 兼容边界

- 原版扣血发生于下一反应步，NewKOF 在接触 tick 原子提交。原版共用 RNG，NewKOF 每席独立。验证器使用各自的补正和取整规则重算结果。
- F23 同边沿回落的命中和格挡样本均在 L37 开始新的 200。之后的独立第二拳沿用阶段 18 已知的通用受击框与续防限制，原版空挥，NewKOF 在 L40 命中。该样本没有 Wave 实体。新 Helper 的格挡命中发生在目标退出前次格挡硬直以后。详见[阶段 18 差异](STAGE18_COMPATIBILITY.md)。
- 完整对照范围为地面目标。原版晚段命中空中目标会另外击飞，空中防御也有独立速度，实验当前沿用 NewKOF 的通用空中反应。原版起身额外的 8 tick 投技保护只复用了其中的恢复控制当帧，实验招式表没有投技。多模式、重版 Power Wave 和 State 205 取消入口仍分别留待对应阶段。
- 首次穿越地平面时，NewKOF 在快照中钳制 Y 至 0。原版在该 tick 为地面以下 6 单位，次 tick 进入相同触地阶段。三场延长运行核对了水平位移、此后反弹、倒地与起身的逐 tick 进度。
