## 运行时事务

`BattleSimulation.Step` 先识别输入并应用动作转换，再推进伤害脚本、收集当前攻击框、检测接触和提交伤害。已提交的权威帧保持原值。取消后的当前帧以 State 1000 tick 0 判定，旧 215 在这一帧及以后均不再参与接触。旧招的攻击段去重由目标保存的 `LastHitAttackStartFrame` 与 `LastHitContactGroups` 表达。目标快照可以保留已提交接触的记录，后续攻击通过新实例起始帧及各自接触组独立结算。

换招重置攻击确认与招式专用分母，角色 RNG、输入历史及已有实体继续按权威时钟推进。原版扣血提交相位与 NewKOF 接触 tick 原子结算继续分别记录。
