## 原始定义

`Terry-KOF98.def` 将 `St1` 指向 `Terry-N.cns`。State 310（1979–2075）在默认与模式 2 都使用 Action 310（`Terry.air:1050–1080`）。StateDef 为 S/A/N、`ctrl=0`、`velset=0,0`、`facep2=1`。没有 `VelAdd`、`PosAdd` 或本体地空转换。AIR 六元素分别持续 3、3、3、11、6、7 tick，共 33 tick。元素 4 起切换 MoveType I，动画结束时回 State 0 并恢复控制。

HitDef 以 `AnimElemTime(2)>=0 && AnimElemTime(4)<0` 覆盖旧 tick 3–8。两段框共用 ID 60，`!movecontact && !movereversed` 防重复，`var(12)>0` 关闭有效 HitDef。属性为 S,NA，`hitflag=MAF`，`guardflag=M`。站防与蹲防可格挡，空中持后不能防御。State 310 无专属无敌控制器。

常规伤害为 `floor((ifelse(var(6),16,13)-var(21))*fvar(7))`，削血 0。普通停顿是施攻／被击 11／13，格挡 11／11。地面 Hard／High 反应，滑行和硬直参数均为 17，规范 X 击退量 10.5。空中 Back／High，`air.hittime=12`，规范速度远离 4.5、上升 6.5，重力 0.5，`air.fall=1`。反弹上升初速 3.5，`fall.recover=1`、`fall.recovertime=600`。原版特殊加成按 HitDef 的 `var(40)`、Helper 40000 暂停等读取，受控轨迹取普通实验条件。MAX、崩防和通用空战另有依赖。

## 地面入口与权限

`Terry.cmd:1552–1560` 检查 `y && holdfwd && holddown` 或 Helper 99999 的 `var(41)>0`。方向按人物朝向解释。自由入口需要地面可控、State 100／101 或 `var(2)>=1`。Helper 99999 在 `Helper.cns:2213–2222` 把同时成立的组合写成 4，同次减到 3。冻帧中的根方向和按键各有缓冲。地面自由、提前入口及自然恢复都经同一 CMD 候选竞争。

NewKOF 物理键为 P1 `S`＋`D`／`A`＋`K` 与 P2 `Down`＋`Left`／`Right`＋`KP2` 或 `.`，前方向取各席当前朝向。出招后按 `facep2=1` 对准对手。固定原版预设的 `var(9)=1`，双前走 State 110 前跳。空中的 DF+y 探针未进入 310。真正的 State 100／101 跑步入口需要 `var(9)=0`，留在源规则表内。

原版全局 Pause 样本 F103 记录实体物理输入 DF+y，Helper 41 在同轮末写成 3，F104 以根输入中立、Helper 41 仍为 3 进入 310。F102 在 1000 旧 tick 52 自然接 310，F104 新物理组合也能直接发动。双键 y+b 中立进 250，下进 410，前下进 310。F+x+y 进 300，DF+x+y 进 310。距离 36 的 F+y 原版可进 800，F+b 对应 805，两条投技资格均要求非下方向。阶段 30 不实现其本体。

F104 新 DF+y 的原版轨迹先经 IKEMEN GO `src/char.go:12256–12261` 的基本动作进入 State 10、Time 0，再经 CMD 进入 310。此前弱 Wave 已设置的 `var(31)` 使 State −2 的偶数 Time 条件请求 F105 及后续 F108 暂停。F103 缓冲样本在 F104 消费时物理下已松开，直接从 State 0、Time 1 进入 310，后续暂停位置不同。
