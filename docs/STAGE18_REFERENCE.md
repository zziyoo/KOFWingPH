# 阶段 18 原版站轻拳重进基准

## 取证条件

沿用[阶段 17 的固定引擎与角色](STAGE17_REFERENCE.md)。原版 IKEMEN GO `5dac5caf9a02a9b81bf2264e88a1bbf68e21bba0`、`Terry-KOF98.def` 双 Terry、KFM 场景、种子 1337。F0 是 RoundState 2 的首个逻辑 tick。夹具设定开局间距和朝向，随后只经原版 InputUpdate 注入物理按键。模式 2 通过原版调色板和开场 `Grant` 序列进入 `var(10)=2`。镜像反转两席开局坐标、朝向和方向键。

原版 Helper 99999 的 `keyctrl=1` 使用独立命令缓冲。夹具向根角色和该 Helper 提供相同物理输入。观测记录包含 `before-command`、`after-command`、`hitdef`、`after-collision`、`end`，以及进入或离开 200／205 的精确 `state-change`。同状态重进也有独立记录。状态事件中的 `elem` 为零基，`stateTime` 为执行旧控制器前的时间。F+1 扣血是原版反应处理时序。NewKOF 在接触 tick 原子提交。

## 恢复窗口和输入

首个物理 `x` 在 F5，远身空挥间距 100。State 200 和 205 均使用原始动作 3／4／5 tick。显式站轻拳重进在原版 State −1 的旧 `stateTime` 7–11，第三元素开始时开放。F12 是空挥首次可重进帧，F16 是最后一帧。

- F9 预按后保持到不了 F12。F10、F11 的单次预按均在 F12 生效。F12 的根角色 `xBuffer` 已空，Helper 的 `var(0)` 分别为 1、2。F12 直接按下则由根角色命令接受。F10 或 F11 开始按住第二次输入也只重进一次。
- Helper 在物理命令帧设置 `var(0)=3` 并同一 Helper tick 减至 2。根角色 State −1 在后续两个帧可读取 2 和 1。始终按住第一次 `x` 不产生第二个命令。
- F16 直接输入在旧时间 11 重进，`ctrl=false,var(2)=0`。F17 已到旧时间 12、`AnimTime=0`，源 State −2 设置 `var(2)=1`，随后一般站轻拳控制器直接进入新 200。这是原版末端普通启动，属于显式 7–11 收招规则之外。没有第二次输入时 F17 进入 State 0。
- F12 同帧按 `x+y`，两个命令都有效，实际重进 200。只按 `y` 则在显式轻拳窗口内不启动。F11 同按 `x+Down`、F12 松开方向时，F12 经 Helper 重新进入站轻拳。F12 当帧 `x+Down` 在原版进入 State 400 蹲轻拳。Stage 18 的范围限于站轻拳重进。

## 命中、格挡与停顿

中心距 60，P1 F5 出远身轻拳，F8 接触，旧时间推进到 4 后进入 11 tick 攻方 HitPause。F9–19 保持旧时间 4，F20 首次恢复推进，F23 开放旧时间 7 的重进。

- 真实命中样本中，F9、F17、F18、F19 的物理 `x` 能进入原版根角色缓冲，`curbuftime=2` 保持到 F19。F20 衰减为 1，F21 归零。Helper 在根角色冻结时照常衰减，所以这些输入均在 F23 前过期。F20 的新按键也过早。F21、F22 的新按键分别以 Helper 值 1、2 在 F23 重进，F23 直接输入也合法。
- 格挡样本 P2 从 F7 起按后，F8 首次成功格挡，F23 重进。中心距 60 的 200→200 在第二招空挥。中心距 44 的 205→200 在 F26 产生第二次格挡。两次格挡均为 0 削血。显式规则允许首次命中、格挡或空挥后重进。
- 近身地面对局中心距 36 的 205→205 在 F23 重进，旧第一段 F8 伤害 30，新实例 F26 伤害 22。中心距 44 的 205→200 在 F23 重进，旧第一段 F8 伤害 30，新实例 F27 伤害 37。后者 F26 已生成新 HitDef，但受击者仍用素材 5000,10，朝向攻方的身体框最高到 Y −72，头部框不够靠近。F27 换到 5000,0，身体框最高至 −88，才与站远轻拳的 Y [−88,−73] 重叠。NewKOF 沿用冻结的通用地面受击框，可在 F26 对应的首个生效 tick 接触。两边独立验证分支、重启、去重及合法结算。

## 分支和新实例

重进的目标仍由当帧 `P2BodyDist X` 决定。站立命中中心距 36 的重进身体距为 12，选择 205。中心距 44 在第一次命中推退后，重进身体距为 20，选择 200。旧招 ID 与目标 ID 是否相同，不影响新实例初始化。

200→205 用合法跳跃接近复现。P2 F0 向前跳，P1 F13 出轻拳时身体距为 36，进入 200，第一次空挥。P1 F20 再按 `x` 时，旧时间 7、身体距 11.5，进入 205。起始中心距 94.5 时，重进身体距恰为 16，进入 205。起始中心距 95 时，重进身体距 16.5，进入 200。默认、模式 2 和镜像均采集。Godot 对照使用地面接近并短暂蹲伏避开首次攻击，核对首招空挥、重进入口、近远分支和真实素材。原版前跳轨迹、空中受击及 Y 方向判定保留在其原始证据中。

显式重进提交帧显示新动作的首张真实素材，StateTime 已推进至 1，素材仍是元素 0、元素时间 0。旧 `MoveContact`、`MoveHit` 和 `MoveGuarded` 均已清零。新 HitDef 在重进后第 3 tick 出现；近身命中和格挡样本证明新实例能重新结算。源 CMD 仍包含蹲轻拳、轻踢、特殊技和其他 Helper 命令路径，阶段 18 只覆盖表中两种站轻拳。
