# 阶段 16 Terry 近身普通技接入计划

**目标**　以同一实验角色的轻拳和重拳指令自动选择近身 205/215 或远身 200/210，并保留重拳的两套原版动作预设。阶段 14/15 配置、默认 Kai/Rei、快照语义及 13C 标签作为回归基线。

- [x] 复用 IKEMEN 取证器采集两个预设的近身状态、判定、停顿及恢复。对照 CMD、CNS、AIR 与引擎 `P2BodyDist X`，确认轻重拳边界、第一次命中或防御对第二段的影响及合法落空路径。
- [x] 由离线转换器生成独立双预设。角色数据定义地面身体宽度与近身条件。指令识别后从同指令的有序候选选择，入招后继续由原招式身份驱动。
- [x] 以单招式内显式接触组支持 215 的两段。仅为实测行为扩展已有防御、结算及快照数据。通过专项测试覆盖边界、两席、距离变化、打断和重放。
- [x] 用真实 Godot 4.7.2 Mono/Vulkan 验收四招式、两预设、双方朝向、停顿、恢复及实时 30/60 FPS。对照采用确定的入招零点，保留原子扣血的相位差异。
- [x] 运行阶段专项、Debug、全量和 15/14/13C 权威日志回归。整理各阶段证据，分别提交并核对远端，保留现有 `project.godot` 差异。
