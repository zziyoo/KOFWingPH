# 阶段 21 Terry 近重拳取消实施计划

范围为默认模式 State 215→1000、215 两个接触组及现有取消路径共存。模式 2 只检查普通技、重进和 1050 边界。以阶段 20 的冻结预设为基础生成新实验预设。

1. 复用 IKEMEN GO 取证，核对 State −2 许可、CMD、两个 HitDef 及窗口边界。用相同初始条件区分取消所在 tick 的第二段接触、已提交接触、双段停顿和拒绝。验收以实际控制器和轨迹为准。
2. 用专项断言核对取消前后的旧实例、新实例、命中确认、接触组、RNG 和恢复。优先为默认 215 配置添加一条现有取消定义。共享执行器只有出现可复现差异时才修改。
3. 在实际 Godot Vulkan 中重放原引擎矩阵和多来源对照。固定帧核对第二段预定时点与实体生命周期，实时稀疏采集实际帧率、提交版本和画面。分别记录视觉覆盖开关一致性与原版差异。
4. 运行专项、全量、Debug 构建和冻结门禁。验收结论逐项记录在阶段文档中，提交前检查配置哈希、历史标签和 `project.godot` 原有差异。
