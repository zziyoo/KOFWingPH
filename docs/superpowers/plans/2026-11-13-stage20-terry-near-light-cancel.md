# 阶段 20 Terry 近身轻拳取消实施计划

范围为默认原版模式 State 205→1000 与已通过的 200→1000 共存。阶段 19 的配置、代码行为和权威证据是冻结基线。双预设分别检查原版分支。默认模式进入 1000，模式 2 的 1050 属于另一条实体规则，保留模式 2 普通技与重进，并用原引擎证据标识特殊分支边界。

1. 用现有 IKEMEN GO 夹具补采近身空挥、命中、格挡、窗口边界、根／Helper 缓冲、回落、镜像和双席不同来源。使用物理输入和源角色脚本，保存开局参数及哈希。
2. 从 205 的独立 AIR 动作时序和 State −2 许可生成新预设。优先复用已有 `MoveDefinition.Cancels`、命令、State 1000 及 Helper 1020。生成器与测试保护阶段 19 的冻结预设。
3. 从真实生成配置验证双方来源、旧实例清理、HitPause、近远重进和无效输入。遇到可复现差异先加专项，再按证据最小修复。
4. 复用 Godot 固定帧与 `FramePostDraw` 核对相同输入、局部动作、实体与全局 Pause。实时 30／60 模式检查实际呈现和积压。保留已知原引擎差异及逐帧证据。
5. 候选验收后运行阶段专项、一次全量、Debug 构建和阶段 13C–19 必要权威回归。检查素材与 `project.godot` 哈希，记录矩阵，分别提交并推送。
