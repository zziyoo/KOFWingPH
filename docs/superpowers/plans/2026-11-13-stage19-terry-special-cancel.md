# 阶段 19 Terry 站轻拳取消到弱 Power Wave

**目标**　以原版默认模式的 State 200→1000 为首个纵向验收单元，验证物理 `236+x` 在旧动作的合法窗口内启动新状态。真实命中、格挡和空挥均按原版许可处理。最终将出招、Action 1000 和独立 Helper 1020 的实测规则接到同一场 Godot 对局。

**基础**　沿用 `CommandDefinition`、`CancelDefinition`、`MoveStartedFrame`、冻结动作时钟和既有表现绑定。先独立验证状态入口，再验证 1020 的权威实体。仅经原引擎证实的新增字段可进入独立 Stage 19 预设。原版证据和未证实项目见[源审查](../../STAGE19_SOURCE_AUDIT.md)及[取证](../../STAGE19_REFERENCE.md)。

## 19A 原引擎输入与状态门禁

- [ ] 按已记录的物理轨迹验证普通技命中、站防、窗口内空挥、过早或过晚的合法手势、普通轻拳竞争、纯站立特殊技入口和镜像。记录根角色 CMD 与 Helper 缓冲各自的寿命，区分旧状态的有效动作 tick 与全局帧，保存双方停顿和恢复。F11 完成后立即松开的手势在 F20 解冻仍由根 CMD 消费，Helper 已过期。F17–19 完成的手势同样在 F20 消费。需给 236A 增加可选的自身 HitPause 缓冲保留，保留阶段 18 的站轻拳缓冲。双席同时输入须保留双方控制权及各自实际状态。
- [ ] 同一物理帧可同时成立 Power Wave 和 5A。有效 tick 4–6 的特殊入口优先。旧 tick 7 的原版实测是特殊入口失效、同一个 `x` 回落至站轻拳重进。当前 `RecognitionState.Advance` 对同一边沿只保留胜出的命令，必须在 Stage 19 独立预设中验证按入口资格选取、同边沿最多发动一次及过期清理。旧 tick 3 形成的手势还可经 Helper 在 tick 4 成功，故只做当帧过滤会丢失合法输入。
- [ ] 把自然收招的优先级作为普通启动入口的前置兼容门禁。原版实测在 F16 保留 `y`、F17 完成 `236+x`，旧动作 tick 12 仍优先进入 1000（`var(2)=1`、Helper 重拳值 2）。冻结的 NewKOF 普通入口会先尝试较老的缓冲。Stage 19 若开放该入口，应先在独立预设加同场反例和按合法候选比较的优先级，再接入普通启动。显式生效段 checkpoint 可先验证，保留旧角色的 FIFO 和既有实验预设。

## 19B 角色状态入口

- [ ] 先在 `ComboCancelTests.cs`、`FighterDataTests.cs` 和命令识别专项加入按原版轨迹失败的测试。校验有效 tick、合法与非法输入、HitPause、实际接触是否为必要条件和双席顺序。验证可选的同边沿候选保留和按入口选择，避免双重消费及改动旧 FIFO。保留既有近身／远身选择、同招重进、原子扣血和固定调度。
- [ ] 以新的导入预设映射 236+x、State 200→1000 和真实 Action 1000。核对新实例从 tick 0 开始、旧确认和攻击资格失效、`DamageScript` 的席位 RNG 连续且旧招局部分母重置。第一批范围限默认模式远站轻拳，近站轻拳 205、模式 1／2、重版 1010 和其他入口分别等候原版完整证据。

## 19C Helper 1020 实体

- [ ] 对照已捕获的出生即移动、停速、早段击飞、晚段水平击退、格挡削血、无接触寿命及双实体同帧命中。继续补齐发射者在实体生成前后被外部攻击打断、根角色的伤害变量与 RNG 取样所在事件。固定 1000 角色帧和 1020 实体帧分别绑定真实资源。
- [ ] 复用 `ProjectileState`、现有独立实体以及 13C 的视觉同步；仅为原版证实的移动、判定、生命周期及伤害差异提供可选数据。当前投射物使用常量碰撞盒、固定速度、接触即销毁、无动态伤害及独立停顿配置。未经实体门禁不得把通用火球当作 1020 兼容，也不得把只有入口的 checkpoint 标为阶段 PASS。
- [ ] 单独评估 Helper 命中后 `var(31)` 驱动的周期性全局 `Pause time=1`。已测发射者 HitPause 为 0，原版全局 Pause 仍会推迟双方的世界帧。先用无接触和格挡对照固定局部时钟，再列出命中后的局部时间和世界时间差异。如果全局 Pause 需要新调度能力，保持本阶段现有调度，并把世界时间完全一致列为显式未达项。
